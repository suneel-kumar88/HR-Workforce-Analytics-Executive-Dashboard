# HR & Workforce Analytics Executive Dashboard

After learning and practicing Power BI, I’m excited to share my project: **HR & Workforce Analytics Executive Dashboard**!

An interactive Power BI executive dashboard designed to monitor workforce demographics, employee performance, compensation distribution, attendance, and leave balances across organizational departments and designations.

---

## 📌 Dashboard Overview

![HR & Workforce Analytics Executive Dashboard](https://github.com/suneel-kumar88/HR-Workforce-Analytics-Executive-Dashboard/raw/main/HR%20%26%20Workforce%20Dashboard.png)

This dashboard provides human resources leaders and executive management with a centralized view of key workforce metrics to support data-driven decision-making around compensation, performance appraisal, and resource allocation.

## 🎛️ Interactive Slicers & Filters

* **Department:** Dynamic multi-select filter for all 7 organizational departments.
* **Designation:** Role-based filtering across operational tiers.
* **Performance Category:** Segment data by performance rating.
* **Birthday Filter:** Dropdown slicer for employee birthday tracking and engagement.

---

## 🛠️ Built With

* **BI Tool:** Microsoft Power BI Desktop
* **Data Transformations:** Power Query 
* **Calculations:** DAX (Data Analysis Expressions) for KPIs, ratios, and averages
* **Theme:** Custom dark UI layout with high-contrast KPI cards
